# RoadCAD Lanes
Редактор доріг з автоматичним графом смуг, світлофорами, розміткою та симуляцією трафіку (Vanilla JS + Canvas 2D). Без сервера і без залежностей від CDN.

## Запуск
Покладіть `index.html`, `app.js`, `style.css` в одну папку й відкрийте `index.html` (або опублікуйте через GitHub Pages: Settings → Pages → branch `main`, root).

## Інтерфейс (у стилі Cities: Skylines)
- **Угорі — типи:** Малі · Середні · Великі · Автомагістралі · Мости й тунелі · Розмітка. Клік по типу відкриває панель підтипів з мініатюрами; повторний клік (або Esc) закриває.
- **Ліворуч — інструменти:** режим (пряма/крива), висота (тунель/земля/міст), паралельне будівництво, додавання смуг, сітка, прив'язка до смуг.
- **Угорі праворуч:** ▶ трафік, ↶ скасувати (Ctrl+Z), 💾 зберегти, 📂 відкрити, 🗑️ очистити (можна скасувати).

## Дороги
- Нова дорога на торці існуючої сідає **смуга в смугу** (лінії смуг збігаються), перехрестя — із заокругленими кутами; смуги з'єднуються з найближчою за бічним зсувом.
- Односторонка поруч із краєм смуг — **нова смуга** (сторона дороги визначає напрям). Односторонка від/до тіла траси — **з'їзд/заїзд** (кут задає рука). Дорога іншого рівня від торця — рампа міст↔земля↔тунель.
- Перемальовування на тому самому місці нічого не дублює (той самий тип — ігнорується, інший — оновлює тип); подовження додає лише новий шматок.

## Розмітка (38 видів)
Лінії (суцільна, переривчаста, подвійна, суцільна+переривчаста, реверсивна, крапкова, зигзаг, краєва, парковка, кольорова смуга, бордюр), стрілки (прямо, ліворуч, праворуч, комбінації, розворот, злиття), переходи (зебра, драбинка, континентальний, дві лінії), стоп-лінія, «Дай дорогу», штриховка, шеврони, жовта сітка, лежачий поліцейський, шумові смуги, велосипед, БУС, інваліди, паркомісце, обмеження швидкості, довільний текст.
Для кожної задаються довжина, ширина, крок, **кут у градусах**, колір (штриховка — ще кут штрихів). Штампи прив'язуються до смуги/осі дороги (вимикається), лінії — до меж смуг. `[` `]` — повернути на 15°. 🧽 Гумка видаляє розмітку.

## Збереження
💾 — файл JSON (повна точність), 📂 — відкриття; плюс автозбереження в браузері кожні 2 с (відновлюється при запуску).

## Трафік
IDM, перестроювання (обгін і перед поворотом), світлофори лише в доречних місцях, правило проїзду перехрестя (без накладань), збереження трафіку під час будівництва.
