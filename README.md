# RoadCAD Lanes
Редактор доріг з автоматичним графом смуг і трафіком (Vanilla JS, Canvas 2D, Three.js). Без серверної частини.

## Запуск
Відкрийте `index.html` у браузері або опублікуйте репозиторій через GitHub Pages (Settings → Pages → branch `main`, root).

## Структура
| Файл | Призначення |
|---|---|
| `js/catalog.js` | каталог пресетів доріг (малі, середні, великі, магістралі, мости/тунелі) |
| `js/core.js` | стан `S`, камера, геометрія, `SpatialHash`, bbox-хелпери |
| `js/network.js` | додавання доріг, авто-перехрестя, об'єднання односторонок у смуги, граф смуг |
| `js/sim.js` | трафік: IDM, перестроювання, індекс авто по смугах |
| `js/render2d.js` | 2D-рендер: кешовані шари доріг, авто, відсікання за екраном |
| `js/ui.js`, `js/ramps.js` | інтерфейс; з'їзди/заїзди (кут задає користувач, 0° — міст↔земля) |
| `js/render3d.js` | Three.js: дороги + InstancedMesh для авто, коректний dispose |
| `js/main.js` | головний цикл (фіксований крок 60 Гц) |

## Можливості
- Пресети доріг із тротуарами, деревами, паркуванням, велосмугами, автобусними смугами, трамвайними коліями, розділювачами.
- Прямі й криві (сплайн), рівні Земля / Міст / Тунель, паралельне будівництво.
- Авто-перехрестя (Т, X, прилипання кінців); односторонка поруч із дорогою стає її новою смугою.
- Авто: IDM, перестроювання для обгону, гальмування перед аварією (Alt+клік).
